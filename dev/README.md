# Archivos de desarrollo local

Nada de esta carpeta se sube al sitio real.

- `mu-plugins/local-sin-correos.php`: copiar a `wp-content/mu-plugins/` en el entorno local
  para que WordPress no envíe correos reales a clientes mientras se prueba.
- `wp-config-local-ejemplo.php`: plantilla para crear el `wp-config.php` local.
  El `wp-config.php` real **nunca** se sube al repositorio.
